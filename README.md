## 📖 เกี่ยวกับ One Stop Service (Ultramodern & Premium Web Portal)

**One Stop Service** คือเว็บแอปพลิเคชันรูปแบบ **Progressive Web App (PWA)** ที่รวบรวมลิงก์บริการดิจิทัล ข่าวสาร การเดินทาง สั่งอาหาร จ่ายค่าไฟ ช้อปปิ้งออนไลน์ ตลาดหุ้น และสายด่วนฉุกเฉินทั่วประเทศไทยไว้ในที่เดียว ออกแบบด้วยแนวคิด **"Ultramodern Glassmorphism Portal"** และ **"Zero Friction" (ไม่ต้องสมัครสมาชิกหรือเข้าสู่ระบบ)** สวยงามระดับพรีเมียมด้วยพื้นผิวกระจกฝ้ากึ่งโปร่งใส (Frosted Glass Effect), Ambient Mesh Glow, แถบข้อมูลด่วนวิ่งต่อเนื่อง (Infinite Marquee Ticker), และปุ่ม Floating Action Dock เข้าถึงเครื่องมือสำคัญได้ทันใจ

---

## ✨ ไฮไลท์การออกแบบใหม่ (Ultramodern Glassmorphism Highlights)

- **💎 สไตล์ Glassmorphism & Ambient Glow**: ดีไซน์กระจกฝ้าหน้าใสโปร่งแสง สัมผัสหรูหราทันสมัย พร้อม Ambient Glow Orbs สีสันนุ่มนวล
- **📊 แถบข้อมูลวิ่งต่อเนื่อง (Infinite Marquee Market Ticker)**: ดัชนี SET, ราคาทองคำแท่ง, ราคาน้ำมันขายปลีก ปตท., และค่าเงิน USD/THB เลื่อนอัตโนมัติแบบ Seamless Loop และหยุดชั่วคราวเมื่อชี้เมาส์
- **🔍 ช่องค้นหาอัจฉริยะ (Centerpiece Search Box)**: ดีไซน์ขอบเรืองแสง ค้นหาบริการ ข่าว อาหาร ค่าไฟ หรือสายด่วนได้ทันใจ พร้อมคีย์ลัด `Ctrl + K` หรือ `/`
- **⚡ แถบสถานะและเครื่องมือทางลัด (Compact Status Row)**: แสดงสถานะไฟบ้านแบบเรียลไทม์ ปุ่มเปิดเครื่องคิดเลขค่าไฟ สายด่วน SOS และเช็กเลขพัสดุในแถวเดียว
- **💫 ปุ่มลอย Floating Action Dock (FAB)**: ปุ่มลัดมุมจอล่างขวา กดแล้วขยายป๊อปอัปเมนูเครื่องมือด่วน (Smart Home, Bill Calc, Tracking, SOS) ด้วยแอนิเมชัน Smooth Spring
- **🏷️ แท็บหมวดหมู่แบบ Fluid Pill Tabs**: กรองรายการบริการได้สะดวกรวดเร็ว สลับสถานะนุ่มนวล
- **⭐ บริการที่ใช้บ่อย (My Favorites)**: ปักหมุดบริการโปรดด้วยไอคอน ⭐ พร้อมบันทึกลงในเครื่องผ่าน LocalStorage

### 11. 📦 เช็กเลขพัสดุด่วน (Quick Parcel Tracking)
ระบบตรวจสอบสถานะพัสดุรวมศูนย์ รองรับผู้ให้บริการขนส่งชั้นนำในไทย กรอกหมายเลขพัสดุแล้วกด **"ติดตามพัสดุ"** เพื่อเปิดแท็บใหม่ไปยังหน้าระบบติดตามของขนส่งนั้นๆ พร้อมแนบหมายเลขพัสดุใน URL โดยอัตโนมัติ:
- **ไปรษณีย์ไทย (Thailand Post)**: `https://track.thailandpost.co.th/?trackNumber={TRACK_NO}`
- **Flash Express (แฟลช เอ็กซ์เพรส)**: `https://www.flashexpress.co.th/tracking/?se={TRACK_NO}`
- **J&T Express (เจแอนด์ที เอ็กซ์เพรส)**: `https://www.jtexpress.co.th/service/track?bills={TRACK_NO}`
- **Kerry Express / KEX (เคอรี่ เอ็กซ์เพรส)**: `https://th.kerexpress.com/th/track/?track={TRACK_NO}`
- **SPX Express (Shopee Xpress)**: `https://spx.co.th/m/track?tracking_number={TRACK_NO}`
- **ฟังก์ชันเสริม**: รองรับปุ่มวางเลขพัสดุจากคลิปบอร์ด (Clipboard Paste), บันทึกประวัติการค้นหาล่าสุดในเครื่อง (Search History), และหน้าต่างป๊อปอัป Modal เช็กพัสดุได้จากทุกหน้าจอ

### 12. 🌤️ สภาพอากาศ & คุณภาพอากาศ PM 2.5 (Open-Meteo Real-time API)
ระบบรายงานสภาพอากาศและตรวจวัดค่าฝุ่น PM 2.5 แบบเรียลไทม์ เชื่อมต่อตรงกับ **Open-Meteo API** (Free & No API Key) แสดงผลทั้งใน **Hero Section** และ **แถบ Ticker แนวนอนด้านบน**:
- **อุณหภูมิและสภาพอากาศสด**: รายงานอุณหภูมิปัจจุบัน (°C), สภาพอากาศตามรหัส WMO Weather Code, ความชื้นสัมพัทธ์ (%), และความเร็วลม (km/h)
- **ดัชนีคุณภาพอากาศ PM 2.5**: แสดงค่าความเข้มข้นของฝุ่นละออง (µg/m³) พร้อมแถบสีและเกณฑ์การประเมิน 5 ระดับตามมาตรฐานกรมควบคุมมลพิษ (ดีมาก 🔵, ดี 🟢, ปานกลาง 🟡, เริ่มมีผลกระทบ 🟠, มีผลกระทบต่อสุขภาพ 🔴) และข้อแนะนำในการปฏิบัติตัว
- **รองรับหลายพื้นที่ & GPS**: เลือกระบุเมืองได้ทันที (กรุงเทพฯ, ยโสธร/วชช.ยโสธร, เชียงใหม่, ขอนแก่น, ภูเก็ต) หรือกดปุ่ม **"พิกัดฉัน"** เพื่อดึงพิกัด Geolocation GPS อัตโนมัติ

## 📱 วิธีติดตั้งลงหน้าจอมือถือ (PWA Installation Guide)

### บน iPhone / iPad (iOS Safari)
1. เปิดเว็บไซต์ **One Stop Service** ในเบราว์เซอร์ **Safari**
2. กดที่ปุ่ม **แชร์ (Share Icon)** บริเวณแถบด้านล่าง
3. เลื่อนลงแล้วเลือก **"เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)**
4. กด **"เพิ่ม" (Add)** เพื่อนำไอคอนไปไว้บนหน้าจอมือถือ

### บนมือถือ Android (Google Chrome)
1. เปิดเว็บไซต์ **One Stop Service** ในเบราว์เซอร์ **Chrome**
2. กดที่ปุ่มแบนเนอร์ **"ติดตั้งแอป"** หรือกดเมนู **3 จุด (⋮)** ที่มุมขวาบน
3. เลือก **"ติดตั้งแอป" (Install App)** หรือ **"เพิ่มลงในหน้าจอหลัก" (Add to Home screen)**

### บนคอมพิวเตอร์ (Chrome / Edge / macOS)
1. เปิดหน้าเว็บผ่าน Google Chrome หรือ Microsoft Edge
2. กดไอคอน **Install App (➕)** บริเวณแถบ URL Address bar ด้านบน
3. ใช้งานเสมือนโปรแกรม Desktop ได้ทันที

## 🛠️ การเปิดใช้งานและ Push ขึ้น GitHub


### คำสั่ง Git สำหรับ Push ขึ้น Repository

```bash
# 1. เข้าสู่โฟลเดอร์โปรเจกต์
cd one-stop-service

# 2. เพิ่มการเปลี่ยนแปลงทั้งหมด
git add .

# 3. สร้าง Commit
git commit -m "feat: complete One Stop Service web application with multi-device support, emergency hub, and iHITEK integration"

# 4. ตั้งค่า Branch หลัก
git branch -M main

# 5. เชื่อมต่อไปยัง Remote Repository
git remote add origin https://github.com/fiatnoraset/one-stop-service.git

# 6. Push โค้ดขึ้น GitHub
git push -u origin main
```

### การเปิดใช้งาน GitHub Pages (Free Hosting)
1. ไปที่หน้า GitHub Repository: [https://github.com/fiatnoraset/one-stop-service](https://github.com/fiatnoraset/one-stop-service)
2. เข้าไปที่แท็บ **Settings** > **Pages**
3. ในส่วน **Build and deployment** > **Branch** ให้เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
4. เว็บไซต์จะออนไลน์พร้อมใช้งานทันทีผ่าน URL: `https://fiatnoraset.github.io/one-stop-service/`
