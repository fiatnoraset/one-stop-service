## 📖 เกี่ยวกับ One Stop Service

**One Stop Service** คือเว็บแอปพลิเคชันรูปแบบ **Progressive Web App (PWA)** ที่รวบรวมลิงก์บริการดิจิทัล ข่าวสาร การเดินทาง สั่งอาหาร จ่ายค่าไฟ ช้อปปิ้งออนไลน์ ตลาดหุ้น และสายด่วนฉุกเฉินทั่วประเทศไทยไว้ในที่เดียว ออกแบบด้วยแนวคิด **"Zero Friction" (ไม่ต้องสมัครสมาชิกหรือเข้าสู่ระบบ)** เพื่อให้ทุกคนสามารถเข้าถึงบริการที่จำเป็นได้สะดวกรวดเร็วที่สุดในทุกสถานการณ์

## ✨ ฟีเจอร์หลักและหมวดหมู่บริการ (Features & Services)

### 1. 📰 ข่าวสาร (News & Media)
- [Sanook (สนุกดอทคอม)](https://www.sanook.com/): เว็บท่าอันดับ 1 ข่าวเด่น บันเทิง ดูดวง ตรวจหวย ผลกีฬา
- [Thairath (ไทยรัฐออนไลน์)](https://www.thairath.co.th/home): สำนักข่าวชั้นนำ ข่าวการเมือง เศรษฐกิจ ข่าวต่างประเทศ และรายการสด
- หนังสือพิมพ์เดลินิวส์ ข่าวสด และช่องค้นหาข่าวสาร

### 2. 🍲 สั่งอาหาร (Food Delivery)
- [GrabFood (แกร็บฟู้ด)](https://www.grab.com/th/food/): ร้านอาหารชั้นนำ โค้ดส่วนลดคุ้ม สั่งไว ส่งตรงถึงบ้าน
- [ShopeeFood (ช้อปปี้ฟู้ด)](https://shopee.co.th/m/ShopeeFoodMainDEC): รวมดีลอาหารสุดคุ้ม โค้ดส่งฟรีรายวัน
- LINE MAN Food, Foodpanda และแนะนำร้านเด็ด

### 3. 🚗 เดินทาง / เรียกรถ (Ride & Transport)
- [Grab Car (แกร็บคาร์ / ทรานสปอร์ต)](https://www.grab.com/th/transport/): เรียกรถยนต์ส่วนตัว รถแท็กซี่ รถตู้ เดินทางปลอดภัย
- [Bolt (โบลท์ ประเทศไทย)](https://bolt.eu/en-th/): บริการเรียกรถราคาสบายกระเป๋า รวดเร็ว
- LINE MAN Taxi และแผนที่เส้นทางรถไฟฟ้า BTS / MRT

### 4. ⚡ จ่ายค่าไฟ & สาธารณูปโภค (Utility Bills)
- [PEA e-Service (การไฟฟ้าส่วนภูมิภาค)](https://eservice.pea.co.th/Account/Login?ReturnUrl=%2f): ตรวจสอบยอดและชำระค่าไฟฟ้าส่วนภูมิภาค
- [MEA Smart Life (การไฟฟ้านครหลวง)](https://eservice.mea.or.th/): ตรวจสอบและชำระค่าไฟ กทม., นนทบุรี, สมุทรปราการ
- **เครื่องคำนวณค่าไฟฟ้าจำลอง**: คำนวณค่าไฟรายเดือนตามหน่วย (Units) พร้อมสูตร FT และ VAT 7%

### 5. 🛍️ สั่งสินค้าออนไลน์ (Online Shopping)
- [Lazada Thailand (ลาซาด้า)](https://pages.lazada.co.th/): ช้อปสินค้าแบรนด์ดัง LazMall คูปองส่วนลด และส่งฟรี
- [Shopee Thailand (ช้อปปี้)](https://shopee.co.th/): แหล่งช้อปปิ้งออนไลน์ยอดนิยม โค้ด Flash Sale และ SPayLater
- TikTok Shop และห้างสรรพสินค้า Central Online

### 6. 📈 ตลาดหุ้น & การเงิน (Stock Market & Finance)
- [SET Overview (ตลาดหลักทรัพย์แห่งประเทศไทย)](https://www.set.or.th/th/market/index/set/overview): ข้อมูลภาพรวมดัชนี SET, SET50, mai
- วิดเจ็ตติดตามราคาทองคำแท่ง (สมาคมค้าทองคำ), ราคาน้ำมันขายปลีก ปตท., และอัตราแลกเปลี่ยนค่าเงิน USD/THB

### 7. 🚨 แจ้งเหตุด่วนเหตุร้าย & สายด่วนฉุกเฉินไทย (Emergency Hotlines)
รวบรวมเบอร์โทรฉุกเฉิน 24 ชั่วโมง พร้อมระบบ **Click-to-Call** กดแล้วโทรออกได้ทันทีบนมือถือ:
- **191**: เหตุด่วนเหตุร้าย / ตำรวจ
- **1669**: แพทย์ฉุกเฉิน / กู้ชีพ เรียกรถพยาบาล (ฟรีทั่วประเทศ 24 ชม.)
- **199**: ดับเพลิงและกู้ภัย / สัตว์เลื้อยคลานเข้าบ้าน
- **1155**: ตำรวจท่องเที่ยว (Tourist Police)
- **1193**: ตำรวจทางหลวง
- **1197**: ศูนย์ควบคุมและสั่งการจราจร บก.02
- **1137**: วิทยุ จส.100 อุบัติเหตุ จราจร
- **1644**: สถานีวิทยุ สวพ.FM91
- **1599**: ศูนย์รับเรื่องร้องเรียน ตร.
- **1441**: ศูนย์ปราบปรามอาชญากรรมไซเบอร์ (AOC ระงับบัญชีมิจฉาชีพ)
- **1166**: สคบ. สำนักงานคุ้มครองผู้บริโภค
- **1323**: สายด่วนสุขภาพจิต ปรึกษาคลายเครียด 24 ชม.
- **ระบบเสียงไซเรนฉุกเฉิน SOS (Web Audio API)** และ **ปุ่มแชร์พิกัด GPS** ขอความช่วยเหลือด่วน

### 8. 💡 เปิดปิดไฟในบ้าน (Smart Home Lighting - iHITEK)
- **เชื่อมต่อแอป iHITEK**: รองรับ Deep Link `ihitek://` เปิดแอปบนมือถือทันที
- ลิงก์ดาวน์โหลดบน [iOS App Store](https://apps.apple.com/th/app/ihitek/id1453913076) และ [Google Play Store](https://play.google.com/store/apps/details?id=com.hitekhome.smart)
- **Web Smart Switch Simulator**: หน้าต่างจำลองแผงควบคุมสวิตช์ไฟอัจฉริยะ ปรับความสว่าง เปลี่ยนสี และเลือก Scene บรรยากาศ (ผ่อนคลาย, ทำงาน, ดูหนัง, ปาร์ตี้)

## 📱 วิธีติดตั้งลงหน้าจอมือถือ (PWA Installation Guide)

### บน iPhone / iPad (iOS Safari)
1. เปิดเว็บไซต์ **One Stop Service** ในเบราว์เซอร์ **Safari**
2. กดที่ปุ่ม **แชร์ (Share Icon)** บริเวณแถบด้านล่าง
3. เลื่อนลงแล้วเลือก **"เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)**
4. กด **"เพิ่ม" (Add)** เพื่อนำไอคอนไปไว้บนหน้าจอมือถือ

### บนมือถือ Android (Google Chrome)
1. เปิดเว็บไซต์ **One Stop Service** ในเบราว์เซอร์ **Chrome**
2. กดที่ปุ่มแบนเนอร์ **"ติดตั้งแอป"** หรือกดเมนู **3 จุด (⋮)** ที่มุมขวาบน
3. เลือก **"ติดตั้งแอป" (Install App)** หรือ **"เพิ่มลงในหน้าจอหลัก" (Add to Home screen)**

### บนคอมพิวเตอร์ (Chrome / Edge / macOS)
1. เปิดหน้าเว็บผ่าน Google Chrome หรือ Microsoft Edge
2. กดไอคอน **Install App (➕)** บริเวณแถบ URL Address bar ด้านบน
3. ใช้งานเสมือนโปรแกรม Desktop ได้ทันที

## 🛠️ การเปิดใช้งานและ Push ขึ้น GitHub

### คำสั่ง Git สำหรับ Push ขึ้น Repository

```bash
# 1. เข้าสู่โฟลเดอร์โปรเจกต์
cd one-stop-service

# 2. เพิ่มการเปลี่ยนแปลงทั้งหมด
git add .

# 3. สร้าง Commit
git commit -m "feat: complete One Stop Service web application with multi-device support, emergency hub, and iHITEK integration"

# 4. ตั้งค่า Branch หลัก
git branch -M main

# 5. เชื่อมต่อไปยัง Remote Repository
git remote add origin https://github.com/fiatnoraset/one-stop-service.git

# 6. Push โค้ดขึ้น GitHub
git push -u origin main
```

### การเปิดใช้งาน GitHub Pages (Free Hosting)
1. ไปที่หน้า GitHub Repository: [https://github.com/fiatnoraset/one-stop-service](https://github.com/fiatnoraset/one-stop-service)
2. เข้าไปที่แท็บ **Settings** > **Pages**
3. ในส่วน **Build and deployment** > **Branch** ให้เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
4. เว็บไซต์จะออนไลน์พร้อมใช้งานทันทีผ่าน URL: `https://fiatnoraset.github.io/one-stop-service/`
